# Medical-Data-Analysis-SQL

## Project Overview
Analyzed healthcare data using SQL to explore patient demographics, hospital admissions, diagnoses, doctors, and medical records.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Key SQL Concepts
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate Functions
- JOINs
- Subqueries
- CASE Statements
- String Functions
- Date Functions

## Project Analysis / Context
Performed SQL-based analysis on medical datasets to identify patient demographics, admission trends, diagnoses, doctor specialties, and healthcare statistics. Utilized filtering, aggregation, grouping, and joins to extract meaningful insights from structured medical data.

## Project Outcome
Completed 34 SQL queries covering healthcare data analysis and strengthened practical SQL skills for data analytics.
